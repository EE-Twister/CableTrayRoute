Advanced fault network JSON

Leave blank to omit. Source impedances are ohms per phase on each source bus base. Every source requires an explicit EMF, impedance, in-service state, equipment ID, and reference.

Optional fault source-profile history

Requires the exact explicit fault network above. Supply a piecewise-linear real EMF multiplier history for every modeled source from 1 at time zero to one common horizon. This is a quasi-steady balanced RMS phasor history; it is not a measured motor decay, dynamic waveform, DC peak, clearing-time, thermal-damage, or device-rating model. Multipliers change source EMF while retaining source impedance and in-service state; zero suppresses source EMF without opening the source.

Advanced fault evolution JSON

All profiles and conditions are supplied, unverified evidence. Do not infer actual motor decay from nameplate data or use these results to establish protection adequacy.

Optional cable fault thermal screen

Requires a complete fault network and supplied source-history comparison. This conditional single-event screen compares both terminal exposures through a supplied maximum total-clearing time. Choose continuous coverage to check every selected conductor against all generated bus faults and the full length of every generated cable, including faults in other cables. The time and all-source applicability claim are supplied and unverified. Its 90 °C to 250 °C copper thermoset basis assumes one event after adequate recovery. It does not calculate actual device clearing or let-through, retains a visibly limited bus-only legacy mode, does not qualify the cable, and does not complete protection. An evaluated numeric failure triggers bounded next-size conductor trials under the shared load-flow revision budget (set criteria.loadFlow.maxRevisions to 0 for evaluation only). Incomplete evidence, an infeasible candidate, or exhausted revisions blocks Apply.

Advanced cable fault-withstand JSON

Use schemaVersion 1.0.0, cableSelection mode all-modeled or selected with exact cableIds, faultSelection mode all-generated-bus-and-cable-span-faults for full continuous coverage, or all-generated-bus-fault-cases for legacy bus-only coverage, clearing with maximumTotalClearingTimeS 0.1–5, separate reference and applicabilityReference, and appliesToAllModeledSources true. thermal must state copper, maximumInitialTemperatureC no greater than 90, finalTemperatureC 250, singleEvent true, adequateRecoveryBeforeEvent true, and a reference.
