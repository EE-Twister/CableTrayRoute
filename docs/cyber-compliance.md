# Cyber Compliance

Cyber Compliance is a design-stage evidence matrix for electrical automation assets. It screens each asset against NERC CIP-002, CIP-005, CIP-007 and IEC 62443-3-3 SR 1, SR 3, and SR 5. It does not certify compliance or determine legal applicability.

Use **Seed from project** to create candidate records from equipment, panels, and relay/RTU-like one-line components. Complete the asset class, criticality, electronic security zone, firmware version, protocol inventory, remote-access controls, password policy, patch status, and applicability evidence. Run the assessment to identify missing evidence, save the project-backed result, export the matrix to CSV, or include the **Cyber Compliance Evidence Matrix** in a report package.

For remote assets, a pass requires an approved path, MFA, logging, password-policy evidence, and a current patch status. Formal CIP and IEC 62443 assessments need owner-approved boundaries, evidence, and a qualified compliance review.
