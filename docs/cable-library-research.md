# Cable Library Research

## Southwire SIMpull THHN/THWN-2 Copper

The Cable Library ships one source-verified starter construction, **Southwire
SIMpull THHN/THWN-2 Copper 12 AWG**. It is a construction-level starting point,
not a project-approved procurement item.

- Manufacturer: Southwire
- Family/catalog reference: `SPEC10000`
- Construction stored: one #12 AWG copper conductor, THHN insulation, 90 C
  insulation rating, 600 V rating, conduit installation default.
- Evidence status: `source_verified` as of 2026-07-31.

Southwire's official family page identifies the product as 600 V copper
THHN/THWN-2 with PVC insulation and nylon sheath, and states that it is used in
conduit and cable trays for service, feeder, and branch-circuit applications.
It also documents 90 C dry THHN and 90 C wet/dry THWN-2 ratings. [Southwire
SIMpull THHN/THWN-2 Copper](https://www.southwire.com/wire-cable/building-wire/simpull-sup-sup-thhn-thwn-2-copper/p/SPEC10000)

The record deliberately does not infer a SKU/package, owner approval, project
ampacity, cable O.D., pricing, or installation derating. Confirm those against
the purchased product, the applicable code edition, termination limits, and
the project approval process before final design or procurement.
