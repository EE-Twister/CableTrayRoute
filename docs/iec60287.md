# IEC 60287 Cable Ampacity — User Guide

## Overview

The IEC 60287 Cable Ampacity tool estimates steady-state cable current-carrying capacity
with a simplified thermal circuit based on the IEC 60287 equations. The referenced
[IEC 60287-1-1:2023](https://webstore.iec.ch/en/publication/68118) concerns continuous
steady-state rating at 100% load factor. The application's implementation covers a
narrower range than the standard and is **Screening only**.

The **simplified calculator** estimates cable geometry, fixes bedding resistance for multicore
cables, uses an approximate proximity-effect multiplier, sets sheath loss to zero,
uses a fixed armour-loss factor, and approximates conduit air gaps and free-air heat
transfer. Grouping uses a small built-in factor table rather than a site-specific
mutual-heating solution. It does not model sheath bonding arrangements, soil drying,
crossings, or arbitrary multi-circuit geometry. These assumptions are not demonstrated
to be conservative for every installation.

The same page now includes a separate **detailed direct-burial thermal screen**
with explicit radial layers, supplied electrical losses, isolated/spaced/touching
formations, and two publicly sourced reference profiles. It does not use the
simplified calculator's geometry defaults or scalar grouping table. See the
[detailed thermal model guide](cable-thermal-model.md) for inputs, source data,
equations, saved-study behavior, and limits. Both workflows remain screening tools.

The calculator rejects non-finite or non-physical electrical, thermal, and geometry
inputs, including impossible burial or conduit geometry, and guards the final result
against non-finite values. The form reports an actionable input or calculation error
and, in the simplified calculator, leaves the last valid result visible as
historical evidence. The detailed screen clears its displayed output on an
invalid rerun and blocks CSV export until a valid rerun. Manufacturer construction data, a validated
thermal model, and project-specific review are still needed before final cable
selection.

---

## When to Use This Tool

Use this calculator to compare preliminary cable sizes, ambient temperatures, soil
resistivity, and installation assumptions within its simplified model. A project that
requires IEC 60287 calculations, detailed HV bonding/loss models, or complex mutual
heating needs evidence beyond this screen. Record the adopted standard edition and
manufacturer cable data with the engineering deliverable.

For projects using tabulated methods, the [Auto-Size](../autosize.html) and
[International Cable Sizing](../intlCableSize.html) tools provide separate table-based
workflows with their own applicability limits.

## Project-Linked Inputs

When IEC 60287 is opened from a project or sample workflow, selecting a cable circuit links the conductor size, material, insulation, voltage class, phase voltage, and conductor count from the Cable Schedule. Raceway assignments are resolved through standalone conduits and conduits nested inside ductbanks.

The linked conductor size is the cable's actual cross-section (for example 4/0 AWG is 107 mm² and
500 kcmil is 253 mm²), added to the size list as a "project cable" option. It is not rounded up to
the next IEC preferred size, which would overstate the rating. Resistance for sizes between tabulated
values is interpolated on the IEC 60228 table.

For ductbank circuits, the page also links the installation method, burial depth, soil thermal resistivity, conduit diameter, underground ambient temperature, system frequency, and the number of cables sharing the ductbank route. These fields remain editable; changing a linked value marks it as a study override. Selecting another circuit reloads the new circuit and ductbank context before calculation.

## Simplified Calculator Method

### Current Rating Formula (IEC 60287-1-1 §3.1.1)

The steady-state current rating is:

```
I = √{ [Δθ − W_d·(0.5·T1 + n·(T2+T3+T4))] / [R_ac·(T1 + n·(1+λ1)·T2 + n·(1+λ1+λ2)·(T3+T4))] }
```

| Symbol | Description | Unit |
|---|---|---|
| I | Rated current (ampacity) | A |
| Δθ | Temperature rise budget = θ_max − θ_ambient | K |
| W_d | Dielectric loss per unit length | W/m |
| T1 | Thermal resistance of insulation (per conductor) | K·m/W |
| T2 | Thermal resistance of bedding/filler | K·m/W |
| T3 | Thermal resistance of outer sheath | K·m/W |
| T4 | External thermal resistance (soil, conduit, air) | K·m/W |
| R_ac | AC conductor resistance at θ_max | Ω/m |
| n | Number of load-carrying conductors | — |
| λ1, λ2 | Sheath and armour loss factors | — |

### AC Conductor Resistance (IEC §2.1)

```
R_ac = R_dc_θ × (1 + y_s + y_p)
R_dc_θ = R_20 × [1 + α·(θ − 20)]
```

The implementation uses a skin-effect expression and a fixed `0.57` multiplier for
proximity effect; it does not accept actual conductor spacing or bonding geometry.
The built-in DC-resistance table is labeled as IEC 60228 Class 2 data. A full
clause-by-clause verification of these expressions and table entries was not completed
in the current review.

### Thermal Resistances T1–T4

**T1 — Insulation (cylindrical wall formula):**
```
T1 = (ρ_insul / 2π) × ln(1 + 2t / d_c)
```
where t = insulation wall thickness (mm), d_c = conductor outer diameter (mm).

**T4 — Direct burial (Kennelly formula, IEC 60287-2-1 §2.2.1):**
```
T4 = (ρ_s / 2π) × ln[u + √(u² − 1)]   where u = 2L / D_e
```
L = burial depth to cable centre-line (m), D_e = cable outer diameter (m),
ρ_s = soil thermal resistivity (K·m/W).

**T4 — Cable in a duct (IEC 60287-2-1 §4.2.7.2):** the soil term above uses the duct outer
diameter, plus an air-gap term and a duct-wall term:
```
T4' = U / [1 + 0.1 (V + Y θm) D_e]        (D_e in mm)
T4'' = (ρ_duct / 2π) × ln(D_duct,out / D_duct,in)
```
with U = 1.87, V = 0.312, Y = 0.0037 for PVC/PE ducts in earth, θm = 60 °C, ρ_duct = 6 K·m/W.
For a 35 mm cable this is about 0.7 K·m/W. Earlier versions used a fixed 0.10 K·m/W, which rated
cables in ducts above the same cable directly buried.

**T4 — Free air / cable tray:**
```
T4 = 1 / (h · π · D_e)
```
where h = combined natural convection + radiation coefficient ≈ 8–9 W/(m²·K).

### Grouping Derating

Multiple cables sharing an installation route can heat one another. On this page the
group factor comes from the table below, a screening approximation that ignores the
actual spacing. The factors' earlier attribution to a specific IEC 60287-2-1 table has
not been independently substantiated; they must not be represented as a validated
mutual-heating calculation. Use the [Cable Thermal Environment](../cablethermalenv.html)
page for buried groups and duct banks: it computes the mutual heating from the cable
positions with the IEC 60287-2-1 image method (`ΔT4 = ρ/2π · Σ ln(d′/d)`), so spacing,
rows and columns change the result.

Screening factors:

| Cables (n) | Flat spaced | Flat touching | Trefoil |
|---|---|---|---|
| 1 | 1.00 | 1.00 | 1.00 |
| 2 | 0.90 | 0.85 | 0.87 |
| 3 | 0.82 | 0.76 | 0.79 |
| 4 | 0.77 | 0.72 | 0.75 |
| 5 | 0.73 | 0.69 | 0.72 |
| 6 | 0.70 | 0.66 | 0.69 |

## Soil Thermal Resistivity

Soil thermal resistivity ρ_s is the most important site-specific parameter. A moist
loam site (ρ = 1.0 K·m/W) at 0.8 m depth provides better cable cooling than natural
air convection for typical distribution cable sizes (50–300 mm²).

### Illustrative Screening Values

These existing ranges are preliminary defaults, not measured site data or newly
verified standard tables.

| Soil Type | ρ (K·m/W) |
|---|---|
| Very moist clay, irrigation area | 0.5–0.8 |
| Moist loam (IEC 60287 reference) | 1.0 |
| Average soil | 1.2–1.5 |
| Dry sand / loose gravel | 2.0–3.0 |
| Rock (varies widely) | 1.5–2.5 |
| Concrete encasement | 0.8–1.0 |
| Thermal backfill (fluidised cement) | 0.5–0.8 |

**Measurement:** [IEEE 442-2017](https://ieeexplore.ieee.org/document/8353815) covers
thermal-resistivity measurements of soils and backfill using field and laboratory
methods. Select a representative moisture/density basis for the project.
[IEC 60287-3-2:2012](https://webstore.iec.ch/en/publication/1279) concerns economic
optimization of cable size; it is not a soil-resistivity measurement method.

## Common Mistakes

1. **Using 20 °C ambient for above-ground cables** — The IEC reference ambient of 20 °C
   is for cables in ground. Above-ground/tray installations typically use 30–35 °C.

2. **Using ρ_s = 1.0 without site measurements** — This is the optimistic IEC reference
   value. Actual values can easily be 2.0–3.0 for dry conditions, significantly reducing
   the ampacity.

3. **Ignoring grouping derating** — Multiple cables in a trench or tray will heat each
   other. Always apply grouping factors when spacing is less than one cable diameter.

4. **Misidentifying insulation thickness** — Use the data-sheet nominal insulation wall
   thickness, not the total cable outer diameter. For quick estimates, use the
   **Use Default Thickness** button to look up IEC 60502-1 values.

## Cable Thermal Environment page

The [Cable Thermal Environment](../cablethermalenv.html) page rates one cable in four installations at once.

- **Base** is the single-cable rating in that installation at the reference ambient (30 °C air, 20 °C soil).
- **Ambient** is the computed ratio of the rating at your ambient to the base, from the IEC rating formula (`√(Δθ / Δθ_ref)`), not an NEC table factor.
- **Grouping / mutual heating** is computed. Tray and single conduit use the group table; direct burial and duct banks use the image method from the actual cable or duct positions (duct rows × columns, clear spacing, depth).
- **Installation-specific** is 1.0: conduit, tray and burial effects are already inside the base rating.
- The factors multiply exactly to the derated rating, and the limiting factor is the smallest factor below 1.0 ("None" when no derating applies).
- Soil thermal resistivity applies to every buried case (direct burial, conduit and duct bank).
- Sizes between IEC preferred cross-sections (AWG/kcmil) are accepted.
- The optional 24-hour load profile uses the conductor's heat capacity and repeats the daily cycle until it settles. Insulation and soil heat capacity are ignored, so peaks are conservative compared with a full IEC 60853 cyclic rating.
- Not modelled: thermal backfill around the cables, soil dry-out, and concrete encasement.
