# Field observations and punch items

Field View records installation observations against the cable or tray selected by a QR link. Each record has a type, open/resolved/deferred status, optional study-package reference, comments, an as-built note, and optional photo metadata.

Photos are stored as local project attachment data in the browser and are limited to 2 MB each. They are not uploaded to a separate service. Every new observation is placed in the project-save queue so the workflow dashboard and report package identify records that have not yet been included in the next saved project snapshot.

Use the **Field Observations and Punch Items** section in Project Report to include the open-item register, as-built changes, attachment counts, and save state. Resolve an item only after recording its resolution note; final engineering acceptance remains a separate project approval activity.
